# 挂起项

- [ ] 单设备 `xdisplay-device.local` 适配器契约尚未进入本项目。只有通用 watcher 吸纳并稳定后再评估。
- [ ] `displayselect --manual-run` 和 manual marker 尚未由来源实现完成，不得提前声明支持。
- [ ] 多外屏、无盖桌面、不同扩展坞和不同外屏的预接冷启动需要独立实机矩阵。
- [ ] framebuffer 保留策略只用于受控 A/B 诊断；不加入默认配置或设备钩子。
- [ ] logind 合盖策略是系统级独立决策，不随显示脚本自动修改。
- [ ] 隔离目录中的历史文件需满足稳定期和恢复演练条件后才能删除，不纳入本仓库。
